# 牛人榜

> 路由`/smart-money/leaderboard`，里程碑M2。口径见[钱包指标](../metrics/wallet-metrics.md)。

## 1. 工具栏

| 控件 | 行为 |
| --- | --- |
| 链 | Solana / BSC / Base（榜单按单链，不跨链合并） |
| 窗口 | 7天 / 30天 |
| 范围 | 全部 / 聪明钱 / KOL |
| 筛选 | 盈亏金额、胜率、交易数的最小/最大值 |

范围定义：

- **全部**：窗口内在已支持协议上有成交的全部钱包；成本不完整的Token不计入（见§4）。
- **聪明钱**：导入名单＋自动识别（D57/D58）。
- **KOL**：导入时带KOL标签的钱包，显示名称和X链接。

## 2. 表格列

| 列 | 内容 |
| --- | --- |
| 地址 | 头像（按地址生成像素头像）、缩写地址或KOL名称、复制 |
| {原生币} 余额 | 当前SOL/BNB/ETH余额的美元值 |
| {窗口} 盈亏 | 上：已实现＋未实现盈亏美元；下：收益率% （默认降序） |
| {窗口} 胜率 | 盈利Token数 ÷ 有卖出的Token数 |
| {窗口} 交易数 | 上：总笔数；下：买入/卖出 |
| 盈利分布 | 五档Token数：>500%、200%–500%、0%–200%、-50%–0%、<-50% |

## 3. 交互

- 点击地址打开钱包分析弹窗（[05](05-wallet-analysis.md)）。
- 关注按钮M4可用。
- 分页50行；榜单每小时重算一次，页面显示“更新于”时间，翻页固定同一次计算结果。

## 4. 防刷与资格

- 成本不完整（期初余额未知、转入未知成本）的Token不计入该钱包胜率与盈亏。
- 窗口内交易Token数<3的钱包不上榜。
- 合约地址、DEX池地址、已知路由与机器人地址排除。

## 5. 验收要点

- 用独立算例核对一个钱包的盈亏、胜率、分布五档，与钱包分析弹窗一致。
- 7天/30天切换、范围切换、筛选组合正确；翻页期间榜单重算不串版本。

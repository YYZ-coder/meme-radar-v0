# 钱包分析

> 弹窗（从牛人榜、持有者、活动中的地址打开）＋独立深链接`/wallet/{chain}/{address}`，里程碑M2。口径见[钱包指标](../metrics/wallet-metrics.md)。

## 1. 布局

| 区域 | 内容 |
| --- | --- |
| 头部 | 头像、名称（KOL名或“未命名钱包”）、完整地址、复制、浏览器外链；关注按钮（M4） |
| 活跃热力图 | 右上角，近6个月按日方格，颜色深浅＝当日买卖笔数（最少→最多五档），按周一到周日排列，UTC+8 |
| 窗口 | 1天 / 7天 / 30天，影响下方统计 |
| 资产卡 | 总价值（美元）；可用余额（原生币数量＋美元）；已实现盈亏；未实现盈亏 |
| 绩效卡 | 胜率；交易笔数（买绿/卖红）；盈利分布五档百分比＋环形图 |
| 页签 | 最近盈亏 / 活动 |

## 2. 最近盈亏表

每行一个Token：代币＋最后活跃时间、买入（美元＋数量）、卖出（美元＋数量）、剩余（美元＋数量）、未实现盈亏（美元＋%）、已实现盈亏（美元＋%）、总利润（美元＋%）、操作（分享）。按最后活跃倒序，分页20行；点击代币进入Token详情。

成本不完整的行在收益处显示“--”并提示原因（期初未知/转入未知成本）。

## 3. 活动表

时间、类型（买/卖/转入/转出）、代币、数量、美元金额、价格、交易链接；按时间倒序，游标分页。

## 4. 验收要点

- 用独立FIFO算例核对已实现/未实现盈亏、胜率与五档分布。
- 总价值＝原生币＋可估值现货代币之和；无价格的代币单独列出、不计入。
- 弹窗与深链接页面数据一致；关闭弹窗回到原列表位置。

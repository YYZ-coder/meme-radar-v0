# 资金流入

> 路由`/smart-money/inflow`，里程碑M1。字段口径见[Token指标](../metrics/token-metrics.md)。
>
> 演示（真实链上样本＋异常兜底）：[Demo 08 资金流入列表](../demos/08-inflow-query.md)。

## 1. 工具栏（从左到右）

| 控件 | 行为 |
| --- | --- |
| 时间窗 | 1m / 5m / 1h / 4h / 24h，默认1h；切换后表头前缀随之变化（如“1h 交易数”） |
| DEX选择 | 下拉多选，带搜索、全选/清空，每项显示该DEX窗口成交额；按钮显示已选数量（如“DEX 176”） |
| 发射平台 | 下拉多选：Pump.fun、Raydium LaunchLab、Clanker、Four.meme等；与DEX条件取交集 |
| 隐藏 | 打开黑名单（开发者/合约），M4可用；M1隐藏该按钮 |
| 筛选 | 打开筛选抽屉（见第3节） |
| 快捷购买 | 金额输入、支付币、P1/P2/P3预设、设置；M5可用，之前隐藏 |

## 2. 表格列

| 列 | 内容 | 可排序 |
| --- | --- | --- |
| 星标 | 关注Token（M4，未登录点击提示连接钱包） | — |
| 代币 / 时间 | 图标、符号、热度标记、币龄、缩写地址、社交图标（X/TG/官网） | 币龄 |
| 聪明钱持仓 | 当前持有该Token的聪明钱地址数（D28） | ✓ |
| 聪明钱交易 | 窗口内聪明钱买入＋卖出笔数（D29），默认按此降序 | ✓ |
| 市值｜涨跌幅 | 上：美元市值；下：窗口涨跌幅 | ✓ |
| 流动性 | 全部池美元流动性之和（D56） | ✓ |
| {窗口} 交易数 | 上：总笔数；下：绿色买入/红色卖出 | ✓ |
| {窗口} 交易额 | 美元成交额 | ✓ |
| {窗口} 净流入 | 聪明钱买入额−卖出额（美元），正绿负红 | ✓ |
| {窗口} 走势图 | 窗口内价格迷你折线 | — |
| 代币信息 | Top10持仓占比、开发者持仓、狙击手占比等小图标（M3） | — |
| 操作 | 快捷买入按钮（M5） | — |

行点击进入Token详情；复制、社交、星标、买入按钮有独立点击区，不触发跳转。

## 3. 筛选抽屉

每项为最小/最大值输入，空表示不限：市值、涨跌幅、流动性、交易数、交易额、净流入、聪明钱持仓、聪明钱交易、持币地址数、创建时间（单位分钟/小时/天）；开关项：开发者已清仓/未清仓、有Telegram/Twitter/Github/官网。

- 草稿与已应用分开：点“确认”才生效并回到第一页；“重置”恢复默认。
- 已应用的条件数显示在“筛选”按钮上，并写入URL，刷新与分享可恢复。
- 筛选只作用于查询结果，不影响后台采集。

## 4. 分页与刷新

- 无限滚动，每批50行；首次查询固定前2,000个Token的顺序，翻页不重复不遗漏（实现见[API](../engineering/07-api.md)）；排序值相同按Token ID稳定排序。
- 每10秒刷新可见行的数值，不重排；用户点击排序或筛选才重新排序。
- 列表只收录：窗口内至少1笔成交且在已支持协议内的Token。

## 5. 验收要点

- 表头文字、顺序、上下两行组合与第2节一致；切窗口表头前缀跟着变。
- 同一Token多池时只出现一行，金额为合计。
- DEX＋发射平台＋筛选组合查询结果与后台SQL独立核对一致。
- 未知值显示“--”，不显示0；URL深链接、返回后恢复查询条件。

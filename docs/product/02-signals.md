# 信号

> 路由`/smart-money/signals`，里程碑M3。决策D60。
>
> 演示（真实链上样本＋异常兜底）：[Demo 06 聪明钱与信号](../demos/06-smart-money-signals.md)。

## 1. 什么是信号

信号是“某一时刻、按固定规则判断出的聪明钱集体行为”，与普通成交动态不同：触发时的数据被**冻结保存**，之后只更新“实时数据”和“涨幅”。

**默认触发规则（D60，可调）：**

- 同一Token，在所选窗口（1m/5m/1h/4h/24h）内，**≥3个不同聪明钱钱包**发生净买入（买入额>卖出额）即触发买入信号；卖出信号对称。
- 同一Token同方向30分钟内只触发一次（冷却）；冷却后再次满足条件，“今日第N次推送”加1。
- 只用链上发生时间在触发前的事实；历史补采进来的旧成交不触发新信号。
- “今日”按UTC+8自然日计。

## 2. 卡片布局（四列网格）

| 区域 | 内容 |
| --- | --- |
| 头部 | 图标、名称、缩写地址、社交图标；右上角“距首次推送涨幅 NX” |
| 信号数据（触发时冻结） | 流动性、平均买入市值、持有者数 |
| 实时数据 | 流动性、市值、持有者数 |
| 状态行 | “34m以前 买入/卖出”标签；右侧“今日第N次推送” |
| 聪明钱行 | “N个聪明钱 正在交易”；右侧“资金净流入 $X” |
| 买卖比例条 | 绿色买入%、红色卖出%（按金额） |

字段口径：

- **距首次推送涨幅** = 当前市值 ÷ 当日首次推送时市值，向下取整显示为NX（不足1倍显示0X）。
- **平均买入市值** = 触发窗口内各聪明钱买入时的市值，按买入金额加权平均。
- **N个聪明钱正在交易** = 触发窗口内有买卖动作的聪明钱地址数（实时更新）。
- **资金净流入** = 触发窗口内聪明钱买入额−卖出额（美元，实时更新）。

## 3. 交互

- 顶部窗口选择与资金流入共用；链选择共享。
- 点击卡片进入Token详情；快捷买入按钮M5可用。
- 新信号出现在左上方；每10秒刷新（M4起推送）。

## 4. 数据与存储

- `signals`表：筛选与排序用的字段单独成列（Token、方向、窗口、规则版本、名单版本、触发时间、首次推送市值、钱包数、净买入额、当日序号、状态），参与钱包明细等完整触发快照放JSON（D94，见[数据模型§6](../engineering/06-data-model.md)）。
- 触发快照写入后不修改；若参与成交被重组撤销，信号标记“已撤销”并保留记录。

## 5. 验收要点

- 构造3个聪明钱在窗口内买入的样例，恰好在第3个钱包时触发，冷却期内不重复。
- 触发快照不随后续数据变化；实时数据与涨幅随刷新变化。
- 历史回填的成交不产生新信号。

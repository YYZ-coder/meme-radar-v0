# 管理后台

> 路由`/admin/*`，里程碑M1起。仅管理员可访问，服务端鉴权；匿名或凭证错误返回403。M1用`RADAR_ADMIN_TOKEN`（D106）；M4改为钱包签名会话＋地址白名单。

## 1. 聪明钱名单导入

- 上传CSV或JSON，字段：`chain`、`address`、`label`（可选，如KOL名称）、`tags`（可选，如`kol`）、`twitter`（可选）、`source`（来源说明）。单文件≤10,000行、≤5MB。
- 流程：上传 → 预览（逐行显示有效/格式错误/重复）→ 确认导入。确认时生成新的名单版本。
- 同一地址多次导入只算一个钱包，来源与标签合并保留。
- 拒收含私钥/助记词样式字段的文件。

## 2. 名单管理

- 查看导入名单与自动识别名单（D57/D58），按链、来源、标签筛选。
- 移除地址产生新名单版本；历史版本保留。
- 手动把自动识别的钱包标为“排除”（如机器人），排除后自动识别不再纳入。

## 3. 运行与质量

- 每链采集进度：前向与历史连续完成位置、积压、缺口、最近错误。
- 每协议解析进度与失败任务；手动重试。
- RPC请求量与费用估算、预算阈值（见[运维](../engineering/10-operations.md)）。

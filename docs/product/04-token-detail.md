# Token详情

> 路由`/token/{chain}/{address}`，基础M1、标签与代币信息M3、交易面板M5。

## 1. 布局

左侧主区：头部 → K线 → 下方页签；右侧栏：交易面板（M5）→ 我的持仓 → 代币信息卡 → 窗口行情摘要 → 开发者信息 → 同名代币。

## 2. 头部

图标、符号、名称、编辑/热度/AI洞察标记（AI洞察M5后）；币龄、缩写地址、社交图标、开发者持仓百分比；右侧大号市值，及价格、24h交易量、流动性、代币检测（风险项数，M5后）。分享按钮。

## 3. K线

| 功能 | 第一版 |
| --- | --- |
| 周期 | 1秒、30秒、1分、5分、1时、1天（D105） |
| 价格/市值切换 | 支持 |
| USD/原生币切换 | 支持（D53） |
| 指标 | MA、EMA、VOL、MACD、RSI、BOLL |
| 显示标记 | 聪明钱、KOL、开发者买卖点；我的交易与关注钱包标记M4–M5 |
| 截图、全屏、设置 | 支持 |

图表库默认采用TradingView Lightweight Charts（Apache-2.0，免费）；完整版TradingView需申请授权，不默认使用。K线基于主池（D55）成交生成；切换主池时连续拼接并在图上标注。

## 4. 下方页签

| 页签 | 内容 | 里程碑 |
| --- | --- | --- |
| 活动 | 成交流：时长/时间、类型（买/卖）、市值、数量、总计USD、交易者（地址＋标签）、交易链接；地址类型筛选：全部、KOL、老鼠仓、聪明钱、鲸鱼、狙击手、开发者、关注地址、捆绑交易（每项显示数量） | M1（标签筛选M3） |
| 持有者（N） | 排名、地址＋标签、持有量、占比、买入均价、卖出均价、已实现/未实现盈亏、原生币余额；可筛选聪明钱/标签 | M1（盈亏M2） |
| 流动性 › 流动性变化 | 添加/移除、两侧数量、总价值、地址、时间、交易链接 | M1 |
| 流动性 › 流动性池 | 交易对＋DEX/版本、流动性、两侧储备、池地址、创建时间、外链 | M1 |
| 开发者代币 | 同一开发者地址发行的全部Token：迁移状态、市值、历史最高市值、流动性、持币地址、24h成交额；顶部发行总数/毕业数 | M3 |
| 仓位 / 成交历史 / 委托 | 当前登录钱包在该Token的持仓、成交、委托 | M5 |

## 5. 右侧栏

- **代币信息卡**（M3）：前10持有者占比、开发者持有、老鼠仓、持有者数、专业交易员数、LP已销毁比例、捆绑交易占比、狙击者占比、DEX付费（是否在DEX Screener付费，M5后）。口径见[标签](../metrics/labels.md)。
- **窗口行情摘要**：5m/1h/4h/24h页签，交易额、净流入、交易人数、买卖笔数与金额。
- **开发者信息**：开发者地址与原生币余额，点击进入钱包分析。
- **同名代币**：同名候选的链、地址、市值、币龄、最近活跃；只做提示，不合并。

## 6. 验收要点

- 多池Token：头部与摘要为合计/主池口径，流动性池页签逐池列出。
- 切换K线周期、价格/市值、USD/原生币后数值一致可核对。
- 活动标签筛选数量与列表数据一致；未归因成交在“全部”中可见、不进聪明钱筛选。
- 持有者页注明快照时间与覆盖范围（D42/D43）。

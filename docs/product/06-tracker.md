# 钱包监控、合集与关注

> 里程碑M4，需要钱包签名登录（D61）。

## 1. 功能清单

| 功能 | 行为 |
| --- | --- |
| 关注Token | 列表/详情星标；底部“观察列表”查看 |
| 关注钱包 | 钱包分析/榜单中的关注按钮；关注后进入“我的收藏” |
| 监控浮层 | 底部“钱包监控”打开：我的收藏 / 实时交易两个页签；可暂停/恢复 |
| 实时交易筛选 | 市值、交易额范围；仅看KOL；隐藏貔貅（M5后有安全检测才生效） |
| 合集广场 | `/trackers`：公开合集卡片（封面、名称、链、介绍、地址数、收藏人数、最近活跃）；搜索、只看活跃 |
| 合集详情 | 成员地址列表：7日盈亏、胜率、交易数、最近活跃；搜索；整体收藏 |
| 我的合集 | 创建/编辑/删除：封面（JPG/PNG≤1MB，400×400）、链、名称、介绍、公开开关；添加成员（单个或粘贴多行，最多500个） |
| 黑名单 | 开发者地址与合约地址两类；添加/删除/搜索；命中的Token在本人列表、信号、提醒中隐藏 |
| 提醒 | 气泡提醒、声音提醒两个开关；关注钱包买卖、关注Token信号时提醒 |

## 2. 规则

- 关注与黑名单只影响本人视图，不改变全局数据与采集。
- 公开合集只展示名称、介绍、成员地址与公开指标；私有合集他人不可读。
- 同一钱包在多个合集/关注中只推送一次提醒。
- 历史补采进来的旧成交不弹提醒。

## 3. 实时推送

M4起列表、信号、监控浮层改为WebSocket推送（D62），设计见[实时推送](../engineering/08-realtime.md)。

## 4. 验收要点

- 未登录点击关注/合集写操作提示连接钱包；跨用户读写私有合集被拒。
- 关注钱包产生买入后，浮层与提醒在5秒内出现（以链上确认后计）。
- 黑名单生效后本人列表隐藏、其他用户不受影响。

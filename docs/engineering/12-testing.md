# 测试与发布

## 1. 测试层次

| 层次 | 运行方式 | 核心断言 |
| --- | --- | --- |
| 单元/固定样本 | 离线，无凭证；金额与解码可加fuzz | 独立计算的期望值、边界、未知成本、幂等、排序 |
| 集成 | 隔离的真实PostgreSQL、模拟上游、生产构建 | 事务、锁、`NUMERIC`、任务领取、REST契约、页面 |
| 真实只读验证 | `make verify-live`显式开启，带请求与费用上限 | 三链真实样本：发行、成交、迁移、余额、价格 |
| 负载/恢复 | 固定机器与数据规模 | 延迟、资源、费用、断线重启、备份恢复 |

CI默认只跑前两层。数据库测试必须用真实PostgreSQL，不用嵌入式库替代。全skip、只编译、只检查HTTP 200不算通过。

## 2. 必测用例

### 采集与解析
- 102失败、103成功：断点停在101，102补齐后推进到103。
- 关闭WS后RPC定时扫描补齐；重复通知不重复落盘。
- 写入Raw、更新任务、推进断点三步之间任意位置崩溃，重启后一致。
- 同高度不同hash按重组处理，旧分支保留，派生结果重算。
- 协议A失败不阻塞协议B；A修复后补齐不重复。
- 历史下界L=700、仅980–999已下载：历史解析停在700等待，前向照常。
- A之前创建的老Token：成交先入库，历史补到创建事件后关联原记录，币龄不改为首次发现时间。
- 区间任务：worker崩溃后租约过期被重新领取；done+skipped+gap＝区间大小才算完成（D81）。
- 缺口块：解析跳过并记录；补齐后作为迟到事实重解析，派生结果重算。
- 失败交易：调用已支持协议的写`chain_txs(success=false)`，其他忽略；不产生成交（D84）。
- 解析器升级：影子分区与正式分区diff不符合预期时不替换；替换在一个事务内完成（D86）。
- 未确认块的事实可查询；重组后被删除并重新解析，已推送事件收到`event.reverted`（D87）。
- `tracked_since`被历史解析改小：取新基线、重放后余额不重复计算。

### 归因与收益
- 钱包未证明的池成交计入行情、不计入钱包统计；补证后归给A，再改判给B时A撤销、B新增。
- FIFO算例一：买100花101、卖40得59 → 释放成本40.4、利润18.6。
- FIFO算例二：接算例一再买50花101，卖120得249 → 释放成本141.4、利润107.6、剩余30个成本60.6。
- 有未知成本批次的Token不进胜率与榜单。
- Jupiter多跳只算一笔；同交易两个独立动作分别计。

### 计价与持仓
- 两池流动性交替领先，满足“领先20%且持续10分钟”才切主池。
- 持仓算例：快照B余额100，之后转入20、转出5 → 115；补到B前买入60，余额仍为115，只补成本。
- 同owner多个Token Account合并；快照未覆盖地址为未知而非0。

### 信号与名单
- 3个不同聪明钱在窗口内净买入触发；30分钟内同Token同方向不再触发，反方向不受影响（D60）；重启不重复。
- 聪明钱自动识别：钱包有一个成本不完整的Token时只剔除该Token，其余满足条件仍入选（Demo 06 W6）。
- 列表翻页期间名单更新，同一次翻页仍用原名单版本。

### 美元价缺失
- 某分钟报价资产价缺失：美元值为NULL；价格补齐后该分钟重算（D85）。

### 登录与会话（M4）
- 同一钱包两台设备登录，一台退出不影响另一台；本端重新连接登录后旧token返回401（D98）。
- 登录钱包切换地址后会话撤销；钱包锁定（`accountsChanged([])`）不撤销。
- 页面加载时钱包尚未自动连接完成，不触发登出。

### WS（M4）
见[实时推送§7](08-realtime.md)。会话撤销后用户订阅的连接被断开。

### 页面
- 未知显示“--”，不显示0；过期数据灰色提示。
- 链切换、筛选、排序写入URL，刷新与返回后状态一致。
- 桌面与移动宽度、键盘操作、加载/错误/空状态。
- 生产构建实际打开页面，与 `product/` 规格逐项对照。
- 中英文切换后所有文案都已翻译（检查翻译文件无缺失键）；数字单位随语言切换。

## 3. 工程门禁

| 命令 | 职责 |
| --- | --- |
| `make setup` | 安装两端依赖与共享pre-commit hook（根目录统一设置`core.hooksPath`） |
| `make check` | 后端与前端全部检查及OpenAPI契约校验 |
| `make dev` / `make stop` | 启停本地开发进程 |
| `make smoke` | 用生产构建与隔离测试库跑关键路径 |
| `make verify-live` | 真实只读验证（需显式开启并设上限） |

pre-commit只检查暂存内容，格式化产生改动时中止并要求重新暂存。CI额外跑Go race与前端E2E。

## 4. 发布与回滚

| 对象 | 方式 |
| --- | --- |
| 应用 | 保留上一版产物；schema兼容时直接切回 |
| 迁移 | 优先向前修复；破坏性迁移需单独计划、备份与演练 |
| 规则/解析版本 | 回到上一版本并重算受影响结果，不删除Raw |
| 数据恢复 | 停写→在独立库恢复→核对→切换→WS换新epoch |

发布清单：版本号、迁移号、解析/规则/名单版本、测试证据、备份位置、已知缺口。

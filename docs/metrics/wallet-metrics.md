# 钱包指标与FIFO收益

> 牛人榜、钱包分析、持有者页、聪明钱自动识别共用。决策D3、D58。
>
> 演示（真实链上样本＋异常兜底）：[Demo 05 FIFO账本](../demos/05-ledger.md)。

## 1. FIFO账本

- 每个钱包×Token一本账；每次买入形成批次（数量、含费用美元成本）。
- 卖出按链上顺序（区块→交易→指令/日志位置）依次消耗最早批次。
- 释放成本＝被消耗部分的批次成本之和；已实现收益＝卖出净到账美元额−释放成本。
- 费用：交易手续费、协议费计入成本或从卖出所得中扣除，不重复扣。
- **未知成本**：期初已有余额（采集起点前买入）、无法确定成本的转入，形成“未知成本批次”；卖出消耗到它时该Token标记为成本不完整。成交所在分钟缺报价资产美元价时，该批次暂按未知成本处理，价格补齐后重算（D85）。
- **闭仓**：剩余持仓价值<$0.01（灰尘）视为已清仓，用于判断“完整闭仓”；余额本身保留。
- **推断归因**：`attribution=inferred`的动作计入账本，但该钱包×Token不进入聪明钱自动识别样本；`ambiguous`不计入（[解析§4](../engineering/03-parsing.md)）。

**算例一（单批次）**：买入100个花费101 USDC；卖出40个净到账59 USDC。释放成本40.4，利润18.6，剩余60个成本60.6。

**算例二（跨批次）**：先买100个花费101、再买50个花费101；卖出120个净到账249。释放成本＝101＋20×2.02＝141.4，利润107.6，剩余30个成本60.6。

## 2. 钱包指标

| 字段 | 定义 |
| --- | --- |
| 总价值 | 原生币余额美元值＋可估值现货代币美元值之和；无价格代币不计入、单独列出 |
| 可用余额 | 原生币数量及美元值 |
| 已实现盈亏 | 窗口内发生的卖出产生的已实现收益之和（成本完整的Token） |
| 未实现盈亏 | 当前剩余持仓按现价估值 − 剩余成本（成本完整的Token） |
| 盈亏（榜单） | 窗口内已实现＋当前未实现；收益率＝盈亏 ÷ 窗口内买入成本 |
| 胜率 | 窗口内有卖出、成本完整的Token中，该Token累计收益>0的比例 |
| 交易笔数 | 窗口内买入经济动作数 / 卖出经济动作数 |
| 盈利分布 | 窗口内有卖出且成本完整的Token，按单Token收益率分五档：>500%、200%–500%、0%–200%、-50%–0%、<-50%；边界归入较低档 |
| 活跃热力图 | 每日买卖经济动作笔数，UTC+8，按全部数据分五档 |

## 3. 归因规则

- 只有确认（或按规则推断）为该钱包付款并收币（或付币并收款）的经济动作才计入；fee payer、路由合约、接收方不等于买家（D25）。
- 一次多跳路由只算一笔经济动作；同一交易内的独立买卖分别计。
- 转入、空投只影响持仓，不算买入。

## 4. 重算

补证、重组、较早成交补齐或报价资产价格补齐后，从受影响点按链序重放该钱包×Token账本；旧结果在一个事务里被整体替换，不叠加（D26，见[派生计算§4.1](../engineering/13-analytics.md)）。

# Token指标口径

> 资金流入、Token详情、信号共用的字段定义。计价规则D53–D56，价格计算实现见[计价](../engineering/04-pricing.md)。

## 1. 基础约定

- **时间窗**：1m/5m/1h/4h/24h，均为截至查询时刻的滚动窗口，按链上区块时间归入。
- **成交**：已支持协议内成功的池级Swap（含发行曲线买卖）；转账、加减流动性、失败交易不算成交。
- **买卖方向**：以Token视角，换入Token为买、换出为卖。
- **美元换算**：每笔成交按发生时（所在分钟）报价资产的美元价换算（D54），由派生计算写入统计与K线，不回写成交事实（D85），也不用现价重算。
- **未知**：缺价格、缺供应量等无法计算的字段返回`null`，前端显示“--”。

## 2. 字段定义

| 字段 | 定义 |
| --- | --- |
| 价格 | 主池（D55）最近一笔有效成交的美元价 |
| 市值 | 价格 × 流通供应量；流通供应量＝总供应量−已销毁（黑洞地址余额）。Pump/Four等曲线阶段的未售出部分按协议计入总量，按总供应量计 |
| 涨跌幅 | (当前价格 − 窗口起点价格) ÷ 窗口起点价格；窗口起点价格＝起点前最后一笔成交价；窗口起点前无成交则用窗口内第一笔 |
| 流动性 | 该Token全部池的美元流动性之和；单池流动性＝两侧储备美元价值之和；发行曲线用曲线内实际报价资产储备×2 |
| 交易数 | 窗口内全部池成交笔数；附买入笔数/卖出笔数 |
| 交易额 | 窗口内全部池成交美元额之和 |
| 净流入 | 窗口内**聪明钱**买入美元额 − 卖出美元额（只算聪明钱） |
| 聪明钱持仓 | 当前余额>0的聪明钱地址数（D28） |
| 聪明钱交易 | 窗口内聪明钱买入＋卖出经济动作笔数（D29） |
| 持币地址数 | 当前余额>0的owner数（Solana按owner合并Token Account） |
| 币龄 | 当前时间 − 经核验Launch时间（D27）；未知显示“--” |
| 走势图 | 窗口内按等分20个桶的收盘价折线 |
| 历史最高市值 | 有记录以来主池最高价×当时流通量；记录早于采集下界L时只能从L算起，标注起始日期 |

## 3. 窗口行情摘要（Token详情右侧）

| 字段 | 定义 |
| --- | --- |
| 交易额 | 同上（全部钱包） |
| 净流入 | 全部钱包买入额−卖出额（注意：这里是全体，不只聪明钱） |
| 交易人数 | 窗口内有成交的去重钱包数 |
| 买入/卖出 | 笔数与美元额 |

## 4. 算例

主池P1（QQQB/WBNB）最近成交价0.00728美元，总供应量10亿、黑洞地址持有0，市值＝728万美元。另一池P2（QQQB/USDT）24h成交额10万美元，P1为20万美元，则24h交易额＝30万美元。

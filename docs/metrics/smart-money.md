# 聪明钱名单

> 决策D57、D58、D30。
>
> 演示（真实链上样本＋异常兜底）：[Demo 06 聪明钱与信号](../demos/06-smart-money-signals.md)。

## 1. 两种来源

| 来源 | 说明 |
| --- | --- |
| 导入 | 管理员上传（见[管理后台](../product/08-admin.md)），可附名称、KOL标签、X链接 |
| 自动识别 | 系统每天按规则从链上数据计算 |

两种来源并集即“聪明钱”；同一地址只算一次，来源都保留。页面可按来源筛选。

## 2. 自动识别规则（D58，默认，可调）

每天UTC+8 00:00用近30天数据重算，单链独立：

1. 近30天成本完整的已实现收益 ≥ $5,000；
2. 近30天完整闭仓（从零持仓到再次零持仓，周期可跨天；灰尘<$0.01视为零）的Token ≥ 10个；
3. 胜率 ≥ 60%；
   - 以上三条只用“成本完整、且动作全部为confirmed归因”的钱包×Token计算；成本不完整或含推断归因的Token剔除，不淘汰整个钱包（D3、[解析§4](../engineering/03-parsing.md)）。
4. 排除：合约地址、池地址、已知路由/聚合器、管理员标记“排除”的地址、单笔中位交易额<$50的钱包（过滤刷量小号）。

不再满足条件的钱包在下一次重算时移出，名单生成新版本。

## 3. 名单版本

- 每次导入、移除、自动重算都生成新名单版本，旧版本保留。
- 列表查询固定首次查询时的版本，翻页不变；刷新使用最新版本（D30）。
- 统计（聪明钱持仓/交易/净流入）按查询所用版本的成员回看窗口内成交。

## 4. 验收要点

- 构造满足/不满足各条件的钱包样例，识别结果正确。
- 同一地址导入两次加自动识别，统计不翻倍。
- 名单版本切换不影响已打开的分页。

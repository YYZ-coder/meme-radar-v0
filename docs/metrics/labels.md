# 地址标签与代币信息

> Token详情“活动”筛选、持有者标签、代币信息卡、K线标记共用。决策D59、D72（捆绑交易规则修订），均为默认规则，可调。标签是规则推断，不代表真实身份。
>
> 演示（真实链上样本＋异常兜底）：[Demo 07 地址标签](../demos/07-labels.md)。

## 1. 地址标签（相对某个Token）

| 标签 | 默认规则 |
| --- | --- |
| 开发者 | 该Token创建交易的发起地址（协议记录的creator） |
| 狙击手 | Launch后前3个区块（Solana前10个slot）内买入的钱包，开发者与捆绑钱包除外；与Launch同区块但无资金关联的买入者也算狙击手（D72）。窗口有采集缺口时等待补齐，24小时仍不完整则标“部分”（`labels_partial`） |
| 捆绑交易 | 须有关联证据（D72）：①与创建交易在同一笔交易内买入；②与创建交易同一bundle内买入（Solana：同slot、交易序号与创建交易连续、该组含Jito小费转账；EVM：同区块且交易序号紧邻创建交易、发送方由开发者注资）；③Launch窗口内买入，且24小时内由开发者或同一地址注资（已知交易所热钱包不算同一来源）。只是同区块买入不算 |
| 老鼠仓 | Launch前或Launch同区块从开发者地址收到该Token、或由开发者地址注资后买入的钱包 |
| 鲸鱼 | 当前持有量 ≥ 流通供应量1%（池地址、销毁地址除外） |
| 专业交易员 | 近7天在已支持协议上交易笔数 ≥ 500笔的钱包（多为机器人或高频） |
| 聪明钱 | 当前名单成员（[聪明钱](smart-money.md)） |
| KOL | 导入名单中带`kol`标签的钱包 |
| 关注地址 | 当前登录用户关注的钱包（M4） |

一个地址可有多个标签；占比统计按地址去重，不重复相加。

## 2. 代币信息卡

| 字段 | 定义 |
| --- | --- |
| 前10持有者 | 前10个owner（排除池、销毁地址）持仓占流通量比例 |
| 开发者持有 | 开发者当前余额占比 |
| 老鼠仓 | 老鼠仓钱包当前合计余额占比 |
| 持有者 | 持币地址数 |
| 专业交易员 | 持有该Token的专业交易员数 |
| LP已销毁 | 主池LP凭证被转入销毁地址的比例（曲线阶段不适用，显示“--”） |
| 捆绑交易 | 捆绑钱包当前合计余额占比 |
| 狙击者 | 狙击手当前合计余额占比 |
| DEX付费 | 是否在DEX Screener购买推广（需第三方，M5后） |

## 3. 验收要点

- 以真实Token样本人工核对开发者、狙击手、捆绑交易判定。
- 标签占比的分母、排除项与持有者页一致。
